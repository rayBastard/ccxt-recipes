# CCXT Recipes — TypeScript

```bash
npm install
npm run price-snapshot            # BTC/USDT across binance, kraken, okx
npm run price-snapshot -- ETH/USDT
npm run ohlcv-to-csv -- BTC/USDT 1h 7
npm run orderbook-stream          # live top of book, Ctrl+C to stop
npm run funding-rates             # BTC/USDT:USDT perp funding
CCXT_SANDBOX_APIKEY=... CCXT_SANDBOX_SECRET=... npm run sandbox-order
```
